# 4x4Chess
A fast-paced 4x4 chess-inspired strategy game where the board starts empty. Players can move existing pieces or place new ones anywhere each turn. Build unique decks with special abilities beyond classic chess. First to eliminate all opponent pieces wins.

## LAN multiplayer

Run `npm run dev` from the repository root on the host computer. Open the Vite Network URL printed in the terminal, then share that address and the room code with a friend on the same local network. The friend must open the host's address before entering the code. Keep the host app running for the duration of the game.

LAN multiplayer uses the host computer's local game server; it does not require a permanently running online server or router port forwarding. It is limited to devices that can reach the host on the same local network.
